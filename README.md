# PEAKFIT - Mais Que Uma Academia

Site institucional da academia CrossFit PEAKFIT.

## Estrutura

```
public/          # Arquivos estáticos servidos em produção
  index.html     # Página principal
  assets/
    images/      # Imagens do site
src/             # Código-fonte (CSS, JS, componentes)
  css/
  js/
  components/
```

## Rodar localmente

```bash
npm run dev
```

Acesse: http://localhost:8000

## Deploy

Conecte este repositório ao Vercel para deploy automático.
